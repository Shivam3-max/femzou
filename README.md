# FemZou Shopify theme

Custom Online Store 2.0 theme. All product and banner images are placeholders until photos are uploaded.

    npm run dev     # local preview at http://localhost:3820
    npm run smoke   # 1600 DOM checks against the running preview

- `theme/` is the Shopify theme. `data/catalog.mjs` holds the 33 catalogue products.
- `docs/SHOPIFY-SETUP.md` covers metafields, collections and import. `docs/SEEDED-DATA.md` lists what to confirm before launch.
- Run git from this folder only. The enclosing folder is a repo of the whole home directory.
